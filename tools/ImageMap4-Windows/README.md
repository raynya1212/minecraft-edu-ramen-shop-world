# ImageMap CLI

This directory is intentionally empty in the public-safe copy.

The generator looks for `ImageMap-cmd.exe` here when creating Bedrock map data for image panels:

```text
tools/ImageMap4-Windows/ImageMap-cmd.exe
```

Download the Windows release of [tryashtar/image-map](https://github.com/tryashtar/image-map) separately and place the files in this folder if you want Image Map panels to be generated.

External executables and DLLs are not included in this repository copy. Check the upstream project's license and redistribution terms before committing any binaries.

# キャラクター画像フォルダ（Image Map 用）

この公開用コピーには、第三者が権利を持つ画像の代わりに、ビルド確認用の自作プレースホルダPNGを入れています。
実際に使いたい画像がある場合は、配布・公開できる権利を確認したうえで同じベース名の画像に差し替えてください。

このフォルダの画像は、[tryashtar/image-map](https://github.com/tryashtar/image-map) のコマンドライン版で Bedrock の地図データへ変換し、
店内・店外の指定位置に **地図＋額縁** として自動配置します。

理由:

- カスタムブロック＋リソースパック方式は Minecraft Education で実験的機能が必要になり、
  Behavior Pack 全体が読み込まれない原因になりました。
- バニラのコンクリブロックへ変換する方式は安全ですが、店内壁が低く、写真のような精細さは出ません。
- そのため現在は、[tryashtar/image-map](https://github.com/tryashtar/image-map) による地図＋額縁方式へ切り替えています。

割り当て:

- `ちいかわとはちわれ.*`: 左壁（map `1000`-`1003`）
- `ちいかわとはちわれ_2.*`: 右壁（map `1100`-`1103`）
- `シーサーと鎧さん.*`: キッチン壁（map `2000`-`2003`）
- `ちいかわラーメン.*`: 店外パネル（map `3000`-`3003`）

画像は2×2枚の地図に分割されます。差し替えたい場合は、上記の名前で画像を置いてから
`py -3.12 build/new_world.py` を実行してください。

## 注意（著作権）

公式キャラクター画像、店舗写真、ロゴ、その他第三者が権利を持つ素材を使う場合は、
権利者の許諾や利用条件を確認し、許可のない公開・再配布は避けてください。このフォルダのプレースホルダ画像は、その確認前に
第三者素材を誤って公開しないための代替画像です。
